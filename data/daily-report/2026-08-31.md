### 5.5 One reported site-wide defect is not a defect — do not fund the fix

#722 reports, under "Generator observations":

> **Site-wide, pre-existing, cosmetic:** every `/who-said/` page renders
> `placeholder="Optional: https://… a link that shows it"` in the source-suggestion form. The entity
> is not decoded in a `placeholder` attribute, so users see the literal `…`. Present on all 1,986
> pages, not introduced here. Worth one central fix in the form template.

The markup is real and is on all **1,981** `/who-said/` pages (the 1,986 figure counts the branch's
five new pages). **The conclusion is wrong.** HTML decodes named character references inside
attribute values. Rendered in the browser the environment actually ships:

```
$ chromium --headless --dump-dom  (input with placeholder="Optional: https://&hellip; a link…")
placeholder="Optional: https://… a link that shows it"
```

Users see a real ellipsis. The same page's search box uses the identical pattern
(`placeholder="Search quotes, authors&hellip;"`) and has rendered correctly for months. **No action,
and no decision number** — recorded here so nobody funds a 1,981-page edit for a bug that does not
exist.

This is separate from **carried item 26** (`plain()` deleting *unmapped* entities), which is real and
measured at 33 records.
