## 4. Traffic

**Traffic: unavailable.** `traffic` came back `null` with `tool_failures: ["traffic: fetch failed"]`.
**This is an analytics outage, not a quiet day — it is not a zero.** 28th consecutive day blind.

This report went one step further than reading the error, because the tool's two code paths
disagreed and the disagreement is itself the finding:

- `node tools/daily-report.js` → `traffic: fetch failed` (a transport error, naming no host and no
  status).
- `node tools/traffic.js` → *"403 from GoatCounter — the dashboard is no longer public. Fix:
  GoatCounter -> Settings -> "Dashboard viewable by" -> Anyone."*

A direct probe settles it. `curl https://quotle.goatcounter.com/` from this container returns:

```
curl: (56) CONNECT tunnel failed, response 403
```

**The 403 comes from this environment's egress proxy refusing the CONNECT tunnel. No request ever
reaches GoatCounter.** So `traffic.js`'s message — the one a human would act on — names the wrong
cause and sends the operator to a settings page that is not the problem. That is item **87**, now
with a direct measurement behind it rather than an inference, and it is why item **43** (flip the
dashboard to public) stays demoted: **it would change nothing.** The fix is item **13** — add
`quotle.goatcounter.com` to the allowlist — or item **43′**, run `node tools/traffic.js` once from
an unproxied machine.

Until then: the last figure this project actually measured is the one in § 4 of the reports before
this blindness began, and it should be read as an **upper bound** (these numbers are not
spam-filtered, and on 2026-09-01 roughly **37%** of attributed referrals were bots impersonating
search engines on `.info` domains). Referrers need the authenticated API: `node tools/traffic.js
--refs`, locally.

## 5. Findings — what the routines actually said

### 5.1 The ✕ that would have called the true author a false credit *(new — item 96)*

The wave's own words, from its prep stage, before anything was built:

> two misattribution rows carried tags `mis-kind.js` does not recognise, so they would have rendered
> the burgundy ✕ meaning *this credit is false* — one of them on **Ferenc Molnár, the true author**,
> on a page whose verdict is that the line is his. Retagged to role tags that resolve to the neutral
> marker, and the Molnár row was dropped rather than shipped with a marker the schema cannot make
> correct. Final state: the only ✕ rows across the wave are Molière and Virginia Woolf, which are the
> two genuine refutations.

This report checked that against the generator rather than repeating it. `tools/mis-kind.js`'s own
header says so explicitly:

> CONSERVATIVE BY DESIGN. Marking a genuine refutation as context SOFTENS A DEBUNK, which is worse
> than the ✕ being wrong — the page exists to refute. […] **Anything it does not recognise keeps the
> default ✕ and is left for a human.**

That default is right for the case it was written for and **wrong for the case it never considered**:
a row whose subject is the record's *own* author. Softening a debunk about the person you are
crediting is not softening a debunk — there is no debunk. The rule is mechanical and narrow: if a
misattribution row's subject equals the record's own author, it can never be a refutation. This is
the same family as items **95 / 75 / 6-76-80** (the magnet who is the true author, the magnet who
quoted it correctly) and it is the fourth distinct face of that confusion; unlike the others, the
failure mode here is a **published visual claim about a named living-or-dead person**, not a metadata
field.

### 5.6 A genuine discovery, recorded here so it is not lost in a merged PR body

The wave verified *"today I consider myself the luckiest man…"* against **Sid Feder's Associated
Press report in the *Evening Star*, 5 July 1939, p. 14**, read from the Library of Congress OCR — and
found that the **United Press filed the same sentence differently the same afternoon**: *"I want to
say now that I'm the luckiest man on the face of the earth."* Both 1939 wire reports read
**"the face of *the* earth"**; every full text in circulation today reads **"*this* earth"**. The page
says so.

swift, but that is where to look."* — with Runyon's own 1945 column objecting that *Bartlett's* had
given it to Adams, *"only I think Hughy Keough said it first."*
