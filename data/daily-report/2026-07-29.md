### 3 · `gh-rest.js` is rate-limited to zero in the cloud, taking the merge gate with it

The report tool's three GitHub reads all returned **403** on this run. Not a proxy denial — GitHub's
anonymous rate limit:

```
{"message":"API rate limit exceeded for 34.29.237.63. …"}
node tools/gh-rest.js --probe  →  status 403 · ratelimit 60 · ANONYMOUS
```

PR #246 established the design as *"NO CREDENTIAL NEEDED, measured rather than assumed… The anonymous
limit is 60/hr; a merge-gate run with 4 open PRs costs ~57 requests in the worst case."* The
measurement was right and the budget is wrong, because **the 60/hr is per source IP and the cloud
egress IP is shared** — this run found 0 of 60 remaining before making a single call.

The mechanism: Node's `fetch` ignores `HTTPS_PROXY`, so `gh-rest.js` goes out direct and anonymous.
Everything routed through the configured proxy is authenticated at 15000/hr. Verified both ways:

```
node        → 200, limit 60,    remaining 0
NODE_USE_ENV_PROXY=1 node → 200, limit 15000, remaining 14993
```

Consequences: **`merge-gate.js` fails closed and loud** (`! cannot list PRs`, exit 1) rather than
reporting an empty queue — the #241 hardening works. But a rate-limited 07:00 pass merges *nothing*,
and routine PRs pile up until someone notices. This report was completed by re-running the tool with
`NODE_USE_ENV_PROXY=1` set in the environment; no tool was modified.

   pipeline still cannot produce it.
2. *"`prep-wave --credited` stamps `creditedTo` on right-person-wrong-words records"* where the credit

   present.** Second consecutive day.
3. *"`DOSSIER_SCHEMA` has no `creatorDescription`, so no wave can emit the `creator.description` the
   CLAUDE.md Schema.org RULE asks for."* Records fall back to `jobTitle`. The wave notes the schema is
   *"~87 bytes under a hard platform ceiling, so this needs space freed first."* This is a standing
   RULE in CLAUDE.md that no routine can currently satisfy.

   source.** It is live as `verified`/`public-domain` with no review stamp of any kind, shipped by a
   wave that said it read no primary page. One tier-2 audit of one record — or pull the page until
   it's done.
2. **Decide whether the other four #193 records count as re-audited.** Discovery stamped them PASS
   without re-fetching any source, which is not what the escalation asked for. Either accept the
   consistency check as sufficient, or queue the four for a source-verifying pass.
3. **Make `gh-rest.js` route through the egress proxy.** Anonymous 60/hr on a shared cloud IP is
   already exhausted, which stops the 07:00 merge pass dead. Either set an undici proxy dispatcher in
   `gh-rest.js` or export `NODE_USE_ENV_PROXY=1` for the routines — a few lines either way, verified
   to give 15000/hr.
4. **Make `daily-report.js` read `data/routine-log.jsonl` as well as `data/routine-log/`.** Today it
   hid nine runs including a `daily-wave` hard failure. Either teach the tool the legacy path, or
   migrate the file's contents into shards and delete it.
5. **Fix `toRecord` so `claimQuoteText` can be set on magnet-author records.** Without it, every
   right-person-wrong-words page ships a banner contradicting its own prose until someone edits the
   record by hand. One condition in two copies of `toRecord`.
6. **Stop `prep-wave --credited` stamping `creditedTo` on right-person-wrong-words records.** Reported
   on 2026-07-28 and again today; it is the input that feeds the bug in 5. One guard in `prep-wave`.
7. **Decide what to do about `creator.description`.** CLAUDE.md carries it as a Schema.org RULE and no
   wave can satisfy it, because `DOSSIER_SCHEMA` has no field for it and is ~87 bytes under a hard
   platform ceiling. Either free the space, or amend the RULE to match what the pipeline can do.
8. **Confirm `reports-close` is actually scheduled.** It missed today only because it merged after its
   own noon slot, but nothing has yet proven the trigger exists. One look at the schedule before
   tomorrow's noon.
9. **Accept or decline the `hardcoded-pd-cutoff-year` detector.** Gate says BACKFILL, 69 hits, 5.9%,
   all correctly reporting 1930 or 1931. Accept with
   `node tools/propose-detector.js /tmp/cand.js --accept`, then a sweep to the "as of 2026" house form.
10. **Widen the egress allowlist, or accept the gap in writing.** monticello.org, archive.org,
    books.google.com and hathitrust are blocked and `founders.archives.gov` returns an empty 202 —
    between them they are the primary route for most Franklin and Jefferson claims. Either add the
    hosts, or record that these sources are permanently unreachable so waves stop spending stages
    rediscovering it.
11. **`REUSE_CHIP`/`RIGHTS`/`USE` 'licensed' is 0/1166** and daily-review has now reported it without
