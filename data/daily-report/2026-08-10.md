## Findings

### 1. Nine pages tell machines that French, German and Latin are English — and no record can fix it

Weekly discovery's detector candidate `quotation-text-not-english` **passed the gate** (9 hits /
1509 records, 0.6%, all 9 hand-checked, 9/9 true positives) but is not accepted, and the discovery
pass flagged that the gate's own remedy is wrong:

> **Note on the remedy:** the gate derives `backfill`, but there is no record field that fixes this
> — `inLanguage` is hardcoded with no override, so the real remedy is generator-side in
> `tools/template.js` (honour `source.inLanguage`, or set it from the text). This pass may not touch
> `tools/`, so nothing here is swept. Flagging that explicitly so the "9 rows to sweep" verdict is
> not read as a record-level job.

`buildJsonLd()` hardcodes `quotation.inLanguage = 'en'`, justified in-comment by *"The DISPLAYED
quote text is always English on Quotle.info"* — but `Quotation.text` is
`schema.quotationText || fullQuote || displayQuote`, so a record that puts the original-language
sentence there ships:

```json
{ "text": "Toutes les histoires anciennes… ne sont que des fables convenues.", "inLanguage": "en" }
```

The record already carries `source.inLanguage: "fr"`; the Quotation node ignores it. The nine:
`blind-belief-in-authority-is-the-greatest-enemy-of-truth`, `carpe-diem`,
`chaos-ist-die-ordnung-des-genies`, `he-who-has-a-why-to-live-can-bear-almost-any-how`,
`history-is-but-a-fable-agreed-upon`, `ich-bin-ein-berliner`,
`if-there-is-a-god-he-will-have-to-beg-my-forgiveness`, `religion-is-the-opiate-of-the-masses`,
`when-you-gaze-long-into-an-abyss-the-abyss-also-gazes`. **→ decision 1.**
