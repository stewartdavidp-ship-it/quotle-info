### 5. `disambiguatingDescription` contradicts itself on right-person-wrong-words records — new

Reported by the wave, deliberately not patched (`git status --porcelain -- tools workflows` was
clean):

> For a `disputed` record whose true author *is* the credited author, `template.js` emits
> `disambiguatingDescription: "This attribution is disputed. Actually by Alexis de Tocqueville."` —
> which reads as self-contradictory, since nobody else is being credited. The visible page handles
> this case correctly (it renders the "Disputed wording — copy with the correction" panel); it is
> only the JSON-LD string that assumes attribution-dispute rather than wording-dispute.

Machine-readable only, so it costs nothing on the page and everything in the channel the site is
explicitly built for. Note `template.js` already distinguishes the two shapes internally — the
`rightPersonWrongWords` predicate exists and is commented at length — so the string has a condition
to key off.
